# EmoSpeak – Speech Emotion Recognition Using Deep Learning

## 📌 Project Overview
EmoSpeak is a deep learning-based application that detects human emotions from speech audio. The system analyzes voice recordings and classifies emotions such as Happy, Sad, Angry, Fear, Neutral, and Surprise. This project demonstrates how Artificial Intelligence can understand human emotions through speech.

## 🎯 Objectives
- Detect emotions from speech recordings.
- Improve human-computer interaction.
- Provide accurate emotion prediction using deep learning.
- Build an easy-to-use interface for users.

## ✨ Features
- Upload speech audio files.
- Extract audio features automatically.
- Predict emotions using a trained deep learning model.
- Display the detected emotion instantly.
- User-friendly interface.

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/EmoSpeak.git
```

2. Navigate to the project

```bash
cd EmoSpeak
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```
